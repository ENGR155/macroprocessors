Results

Recorded software and FPGA checks and the remaining hardware tests.

Overview

The following results summarize the verification record from October 15, 2026. Software and HDL checks have been recorded, but the hardware has not been assembled or tested. We have not demonstrated levitation or measured its performance.

FPGA Implementation

Resource or timing check Recorded result
Logic cells 1971 / 5280 (37%)
DSP blocks 2 / 8 (25%)
Routed maximum clock estimate 45.79 MHz
Required clock 24 MHz; passed

These results were recorded with YoWASP Yosys 0.70 and nextpnr-ice40 0.11.1. The verification build sets top.COMMISSIONED=1 so that the tools include the active design. The source defaults keep the output disabled, and that version was built separately as well.

The timing result is an implementation-tool estimate. We still need to check the clock and external signals on the board.

Software and Simulation Tests

Check Recorded result Scope
Native C compilation Passed Host compilation with warnings treated as errors

Cortex-M4F compilation Seven C files compiled Source compatibility with the checked headers and runtime

FPGA integration simulation Passed ADC sequencing, telemetry, regulation, timeouts, faults, and disabled defaults
Calibration tests Three tests passed Model recovery, degenerate-signal rejection, and nonlinear-fit residuals
FPGA synthesis and routing Passed at 24 MHz Estimated internal synchronous timing

The full GNU Arm executable link and board programming have not been verified. The simulation uses ideal ADC readings and a fixed clock. It does not include a validated model of the physical coil.

Remaining Hardware Tests

Measurement Current status Planned test
Levitation duration Not measured Record a continuous suspension trial
Gap accuracy and repeatability Not measured Compare the estimate with an independent position measurement
Settling and disturbance response Not measured Record target steps and disturbances
Hall estimate during current changes Not measured Hold the object at known gaps and vary the current
External timing and shutdown delay Not measured Capture SPI, PWM, and interlock signals on an oscilloscope
Coil and power-stage temperature Not measured Log temperature at the intended operating point

The first test is to check whether the Hall readings can distinguish changes in object position from changes in coil current. We plan to collect readings at known gaps, fit the calibration model, and validate it with separate data. Current-step tests with a fixed object will check whether the estimate also works during transients.
