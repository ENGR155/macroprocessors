The full GNU Arm executable/runtime link and board-programming workflow also remain unverified. Simulation uses ideal ADC inputs and a fixed clock, not a validated physical coil model.

The next experiment

The first decisive result is whether the sensor arrangement distinguishes object position from coil-current changes. A static numerical fit is insufficient. Hold the object at known gaps, sweep current, reserve independent holdout data, and test transient compensation before closing the position loop.
