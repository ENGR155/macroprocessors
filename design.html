System Design

System architecture and control loops for the magnetic levitation project.

Overview

We designed the system with two control loops. The MCU estimates the position of the object and calculates a current request. The FPGA uses that request to regulate the coil current. The webpage lets the user change the target gap through the course ESP8266 module.

Webpage -> ESP8266 -> STM32 MCU -> UPduino FPGA -> Coil driver

The FPGA reads the current sensor and two Hall sensors through an MCP3204 ADC. These readings are sent to the MCU, which uses them to calculate the next current request. The full system diagram shows the feedback connections and physical interlock.

These rates are design values. We still need to measure timing and stability on hardware.

Position Control

The gap xx is measured downward from the coil. A larger gap means the object is farther below the coil. The force balance is

mẍ=mg−F(i,x).m\ddot{x}=mg-F(i,x).

The approximate relationship F≈ki2/x2F\approx ki^2/x^2 is useful for planning, but the actual force will depend on the coil and object we select. We need to measure mass, lifting force, resistance, inductance, and temperature before tuning the controller.

The position controller compares the measured gap with the target gap and requests more current when the object is too low. It also uses filtered velocity to reduce oscillation. The target changes gradually, and the current request is limited to the configured operating range.

MCU Design

Current Control

The FPGA compares the requested current with the measured current and uses a PI controller to calculate the PWM duty cycle. The controller works in ADC counts and PWM ticks. Normal duty changes happen at the start of a PWM period. A fault can disable the output immediately.

Hall Sensor Calibration

Both Hall sensors measure the field from the coil as well as the suspended object. Using two sensors does not guarantee that the coil field cancels out. The gap estimate also includes the measured coil current:

gap_mm = c0 + c1*Hall1_counts + c2*Hall2_counts + c3*current_A

We plan to fit these coefficients using readings at known gaps and currents, then check the model with separate measurements. Since the ADC reads the channels one at a time, we also need to check whether current changes during a scan affect the estimate.

The initial design assumes that the suspended object contains a permanent magnet with a repeatable orientation. A plain steel sphere would need a different characterization procedure.

Testing Plan

  1. Select the coil and object, then measure force, sensor range, and heating.
  2. Check the sensor scaling, gap estimate, shutdown circuit, and timing.
  3. Support the object and tune the current controller using current steps.
  4. Tune the position controller, starting with proportional and derivative control, then measure settling and disturbance response.

The detailed design contains the control equations and timing calculations. The bring-up procedure describes the planned bench tests.
