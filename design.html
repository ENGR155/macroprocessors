The FPGA drives the power stage through an interlock. Current and two Hall measurements return through an MCP3204 ADC. The MCU compensates the Hall readings for coil current before calculating its next request. The complete system diagram includes the analog feedback and physical interlock paths.

Define the direction first

The gap xx is measured downward from the coil reference plane. Increasing the target lowers the object. A simplified local force balance is

mẍ=mg−F(i,x).m\ddot{x}=mg-F(i,x).

The rough relation F≈ki2/x2F\approx ki^2/x^2 helps identify the system, but it is not a validated model of the eventual coil. Mass, lift, resistance, inductance, and temperature must be measured for the chosen geometry.

Two loops, different responsibilities

The position loop uses the measured gap error and filtered downward velocity to request current. A positive error means the object is too low, so the controller requests more lift. A rate-limited target, saturation, and anti-windup bound that request.

The inner loop regulates measured current in ADC counts. Its fixed-point PI calculation updates the next PWM duty. Normal updates occur at period boundaries; a fault can remove the output immediately.

The central experiment: observability

Both Hall sensors see the coil and the suspended object. Two readings do not automatically cancel the coil field. The local estimator also uses measured current:

gap_mm = c0 + c1·Hall1_counts + c2·Hall2_counts + c3·current_A

Calibration requires known mechanical gaps, current sweeps, and independent holdout measurements. Because channels are sampled sequentially, changing current during a scan may corrupt compensation. Fixed-object current steps are a necessary test before feedback tuning.

The first object should contain a permanent magnet with repeatable orientation. A plain steel sphere is not interchangeable with that design assumption.

Build the evidence in order

  1. Establish the physical system.

    Select a coil and object; measure force, field range, and heating.

  2. Validate sensing and shutdown.

    Check analog scaling, Hall observability, interlock behavior, and timing.

  3. Close the current loop.

    Use supported-object current steps and measured response to tune the PI controller.

  4. Close the position loop.

    Tune PD first, then evaluate settling, disturbance rejection, and operating limits.
