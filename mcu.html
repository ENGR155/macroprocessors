MCU Design

Current 16-bit FPGA readout and remaining control and web integration.

Current bench role

The STM32L432KC is SPI master on the MCU–FPGA link. The FPGA has a separate SPI master for the MCP3204 ADC. ADC ownership therefore differs from the earlier proposal’s MCU ADC/DMA plan.

The current MCU receive program configures SPI1 for 16-bit frames, mode 0, MSB first, at a nominal 125 kHz. It drives chip select low, writes a dummy word to produce 16 clocks, reads the FPGA word, and releases chip select. The result is stored in fpga_word, with read_count tracking transactions. Debug printing and a 500 ms delay make this an inspection program rather than a real-time control loop.

Signal MCU pin FPGA pad
SCK PB3 21
Manual CS PA11 20

PB5 is configured as SPI1 MOSI in the MCU program, but the present FPGA measurement sender has no MCU-command input. The dummy transmit word supplies clocks; bidirectional commands have not been established by this readout test.

Bring-up progress

The November 7 standalone experiment reported 0xA5 / 165 received from the FPGA. Work has since extended to transporting ADC-derived values in 16-bit frames and inspecting two-channel subtraction. Repeatability, framing, stable transfer of a changing word, and signed result interpretation remain under test. A 16-bit SPI container preserves the ADC’s 12-bit result; it does not increase conversion resolution.

The one-byte guide records the earlier test and carrier switch routing. Its embedded 8-bit code is historical; the linked main.c now contains the 16-bit experiment. Use matching MCU and FPGA sources when reproducing a test.

Position estimation and hardware webpage

After reliable acquisition, collect both raw Hall readings at independently measured positions, establish the final sensor geometry, and validate an estimator against separate measurements. The division of estimator and controller work must be finalized with the integrated FPGA path.

The intended hardware webpage will accept a target gap, show requested and estimated position, expose operating status, and support tuning and Stop through the course ESP8266. These remain integration goals. This Quarto report site is separate from that embedded interface.

Earlier application sources

main.c, control.c, board_stm32l432.c, protocol.c, and web.c belong to the earlier full application. Their ADC/DMA ownership and current-command packet should not be treated as the current bench contract.
